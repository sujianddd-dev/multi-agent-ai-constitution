# 决策日志（DECISION_LOG）

> 记录所有**重要决策**及其原因。Agent 与人类都必须遵守已记录的决策，除非本文件明确废弃它。
>
> 规则：**只追加，不删除。** 废弃旧决策时新增一条记录说明原因，并标记旧记录状态为"已废弃"。

---

## 📋 记录格式

```markdown
### [YYYY-MM-DD] 决策标题

- **状态**：✅ 已批准 / 🔄 待讨论 / ❌ 已废弃
- **提出者**：人类 / Agent 名称
- **背景**：为什么需要这个决策
- **决策**：具体决定内容
- **原因**：选择该方案的理由
- **影响**：影响哪些模块/接口/流程
- **关联文档**：更新的文件（如 API_CONTRACT.md）
```

## 🗂️ 决策记录

> 📌 **新增决策的位置**：请将新记录插入到**本标题正下方、第一条历史记录的上方**（最新在上）。
> 追加权限：人类或主 Agent（见 README「治理结构」）；普通 Agent 请提 PR 建议。

### [YYYY-MM-DD] 建立共享知识库（AI 宪法）作为协作基础

- **状态**：✅ 已批准
- **提出者**：人类
- **背景**：多 Agent 协作出现协调成本高、一致性低的问题
- **决策**：以 README.md + 系列规范文档（CONTEXT / ARCHITECTURE / AGENT_GUIDELINES / API_CONTRACT / CODING_STANDARDS / DECISION_LOG）作为所有 Agent 的"宪法"（Truth Source）
- **原因**：低成本（一次性写文档）、高一致（统一剧本）、可扩展（新 Agent 读一遍即可）、人类友好
- **影响**：所有 Agent 工作前必须阅读宪法文档；禁止直接修改 main；接口变更需人工批准
- **关联文档**：全部宪法文档
